مدیریت فایل‌های آموزشی

این ابزار فهرست فایل‌های آموزشی را می‌سازد و خروجی content.json می‌دهد. فایل‌های اصلی (PDF/عکس) را جداگانه در پوشه files مخزن GitHub آپلود کنید.

این پنل روی GitHub Pages به‌تنهایی نمی‌تواند فایل یا تغییرات را روی سایت ذخیره کند. برای انتشار، فایل‌های انتخاب‌شده را در GitHub آپلود و content.json خروجی را جایگزین کنید. این پنل رمزگذاری/ورود امن ندارد؛ لینک آن عمومی است و نباید فایل محرمانه ثبت شود.

پس از ثبت، برای هر فایل باید خود PDF یا عکس را نیز با همین مسیر در GitHub اضافه کنید؛ خروجی JSON فقط فهرست و مسیرها را نگه می‌دارد.
